# Reglas del proyecto

El archivo canónico de reglas está en `REGLAS.md` (raíz del proyecto). Debes leerlo y seguirlo siempre al modificar código.

@../../REGLAS.md

Resumen de reglas vigentes:

## Formato de código

- **NO** agregar líneas en blanco adicionales entre líneas de código al modificar archivos.
- Mantener el estilo de espaciado existente del archivo.
- Respetar la densidad visual original al hacer ediciones puntuales.

## Pruebas

- Puedes usar **Playwright** para hacer pruebas de la aplicación (navegar, interactuar con la UI y verificar el comportamiento de los cambios).
